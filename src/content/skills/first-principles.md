# 第一性原理拆解（First Principles）

**核心信念**：大多数方案都是在既有框架上打补丁——「大家都这么做」让问题被层层假设包裹。第一性原理是把这些假设全部剥掉，回到不可再分的基本事实，从零重建方案。框架是工具，不是牢笼。

## 何时使用

- **显式触发**：用户说「第一性原理」「first principles」「拆回最底层」「剥离假设」「重新推导」「不要被现有方案框住」「从零开始想」
- **隐式触发**：问题被行业惯例、现成方案或「大家都这么做」包裹；现有方案在反复打补丁；用户想突破框架重新思考
- 不适用：简单执行类任务、已有明确最优解的场景、用户只想要现有方案的直接答案

## 阶段一：识别并剥离假设

把问题相关的所有「默认前提」列出来，逐一标记来源，然后**全部放到一边**：

- **别人说的**——权威、专家、KOL 的断言
- **行业惯例**——「这个行业就是这么做的」「标准做法是…」
- **大家都这么做**——从众、路径依赖、「如果它有效大家都会用」
- **现有方案的隐含前提**——当前方案默认了哪些约束，这些约束是否真实存在

剥离动作要有产出：明确列出「被剥离的假设清单」，并区分两类——**真实约束**（物理/数学/客观条件，不能剥离）和**伪约束**（惯例/心理/习惯，可以剥离）。

## 阶段二：追问到不可再分的基本事实

对剥离后剩下的核心，继续追问「为什么」直到不可再分：

- **物理定律**——能量、时间、空间、材料属性的硬边界
- **数学规律**——可计算性、复杂度、统计必然性
- **人类的基本需求**——用户/人真正要的底层结果（不是「要一个工具栏」，而是「要更高效地完成某个动作」）
- **不可再分的判定标准**——再追问「为什么」时，答案已经是定律/定义/需求本身，无法再分解

每个基本事实要能自证：它不依赖任何行业惯例或现成方案。

## 阶段三：从基本事实重建解决方案

只基于阶段二的基本事实 + 用户目标 + 真实约束，重新推导：

- **先定目标函数**：用户真正要的最优结果是什么（可量化更好）
- **再列真实约束**：只有物理/数学/资源/时间这类硬约束能进约束集
- **然后自由推导**：从事实出发、面向目标，允许得出与现成方案完全不同的路径
- **推导纪律**：每个中间步骤都要能指回某个基本事实或真实约束，凡引用惯例的步骤一律标为「未剥离干净」

## 阶段四：输出（4 项）

1. **原方案中只在修补表面的部分**——哪些是补丁、惯性堆叠，没有触及基本事实
2. **从基本事实重新推导出的新路径**——完整、可执行的新方案（可含与原方案的对比）
3. **这条路径成立的前提**——新路径依赖哪些假设/条件（诚实列出，包括它自己的假设）
4. **验证它的第一步**——最小、可执行的验证动作（实验/原型/数据），能最快证伪或证实新路径

## 行为纪律

- **先剥离，后重建**：不剥离假设就重建，只是在换一个框架里打补丁
- **区分真实约束与伪约束**：物理/数学约束必须尊重；惯例/习惯约束可以打破
- **每个推导步骤可回溯**：新方案的每一步都能指回基本事实或真实约束
- **诚实标注新路径自己的假设**：第一性原理不是神谕，新路径同样有前提（阶段四第 3 项）
- **不空谈**：输出必须落到「验证第一步」这样的可执行动作
- 若问题涉及实时事实，可先用 byted-web-search 核实基本事实，再开始推导

# 完成标准

- 阶段一：假设清单齐全，真实约束与伪约束明确区分
- 阶段二：基本事实不可再分、可自证、不依赖惯例
- 阶段三：新路径每一步可回溯到基本事实或真实约束
- 阶段四：4 项输出齐全，含新路径自身的假设与最小验证第一步
